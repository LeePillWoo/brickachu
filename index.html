내 블록 미리보기

블록 색깔 우클릭으로 바꾸기

놀이터 사용법

👀 눈 붙이기: 버튼을 누른 뒤 블록 덩어리를 바로 클릭하면 친구가 돼요.

🐾 동물 친구: 🗂️에서 카테고리를 고르고 동물 버튼을 눌러 불러요. ✏️ 모드에서 친구를 톡 누르면 특수능력을 보여줘요.

✋ 잡아 옮기기: 손 버튼을 고른 뒤 동물을 누른 채 끌어 옮겨요. 기다리지 않고 바로 잡을 수 있어요.

간식 고르기: 버튼을 누를 때마다 🍎 → 🎈 → 🍮 → 🌈 순서로 바뀌어요. 친구를 누르면 먹이고, 바닥을 누르면 놓아요.

🚂 동물 기차: 가까운 동물들이 가느다란 줄로 이어져 칙칙폭폭! 기차를 끌어 길을 그리면 앞의 블록을 부수며 달려요. 눈 붙인 블록 친구와 풍선 친구는 기차에 타지 않아요.

화면 돌리기: 우클릭 드래그 / Alt + 왼쪽 드래그

블록 잇기: 왼쪽 드래그 (컴퓨터)

블록 놓기: 바닥이나 블록을 톡 (모바일)

색깔 바꾸기: 팔레트에서 우클릭

취소: ESC 키
