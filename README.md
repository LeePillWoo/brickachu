# 브릭카츄 (Brickkachu)

블록을 쌓고 33종 동물의 이동·점프·등반·파괴 능력을 관찰하는 Three.js 게임입니다.

## 실행

Node.js가 설치된 터미널에서 프로젝트 폴더로 이동한 뒤 실행합니다. 별도 패키지 설치나 빌드는 필요 없습니다.

```powershell
node serve.mjs
```

브라우저에서 <http://127.0.0.1:8080>을 엽니다. 포트를 바꾸려면 `node serve.mjs 8081`을 사용합니다. 종료는 `Ctrl+C`입니다.

`index.html`을 파일로 직접 열면 ES 모듈의 브라우저 보안 제한으로 실행되지 않을 수 있습니다. 로컬 HTTP 서버를 사용하세요. Three.js와 Cannon-es는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

- ✏️: 블록 추가/제거 전환. 데스크톱은 왼쪽 드래그로 경로 편집, 모바일은 탭으로 한 칸 편집.
- 우클릭 드래그 / Alt+왼쪽 드래그: 카메라 회전. 휠: 확대/축소.
- WASD: 카메라 이동, Q/E: 높이 이동. 블록 경로를 드래그 중이면 Q/E로 경로 높이 조정.
- F: 구조물 전체 보기. ESC: 진행 중인 입력 취소.
- Ctrl+Z: 실행 취소. Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행. macOS는 Command 키 사용.
- 🐾: 동물 소환. 길게 누르면 동물 그룹 선택. 동물 클릭은 특수 동작, 길게 잡으면 이동.
- 🍎: 먹이 배치. 🧹: 동물/먹이 개별 제거 모드. 🧹를 2초간 누르면 동물과 먹이 전체 삭제.
- 💣: 카운트다운 후 블록 폭발. ↻: 카운트다운 취소 또는 폭발 전 구조물 복원.
- ×1/×2/×3: 게임 배속.
