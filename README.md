# 브릭카츄 (Brickkachu)

블록을 쌓고 44종 동물의 이동·점프·등반·놀이 능력을 관찰하는 Three.js 게임입니다. 만든 블록에 눈을 붙여 친구로 만들고, 엉뚱한 간식을 골라 변신시킬 수도 있습니다.

## 실행

설치 없이 바로 플레이: **[브릭카츄 실행하기](https://leepillwoo.github.io/brickachu/)**

GitHub 저장소는 소스 코드를 보는 곳이며, 게임은 위 GitHub Pages 주소에서 실행합니다. `master`에 반영한 변경은 Pages 배포가 성공한 뒤 이 주소에 표시됩니다.

Node.js가 설치된 터미널에서 프로젝트 폴더로 이동한 뒤 실행합니다. 별도 패키지 설치나 빌드는 필요 없습니다.

```powershell
node serve.mjs
```

브라우저에서 <http://127.0.0.1:8080>을 엽니다. 포트를 바꾸려면 `node serve.mjs 8081`을 사용합니다. 종료는 `Ctrl+C`입니다.

`index.html`을 파일로 직접 열면 ES 모듈의 브라우저 보안 제한으로 실행되지 않을 수 있습니다. 로컬 HTTP 서버를 사용하세요. Three.js와 Cannon-es는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

- ✏️: 블록 편집으로 복귀하거나 블록 추가/제거 전환. 데스크톱은 왼쪽 드래그로 경로 편집, 모바일은 탭으로 한 칸 편집.
- 우클릭 드래그 / Alt+왼쪽 드래그: 카메라 회전. 휠: 확대/축소.
- WASD: 카메라 이동, Q/E: 높이 이동. 블록 경로를 드래그 중이면 Q/E로 경로 높이 조정.
- F: 구조물 전체 보기. ESC: 진행 중인 입력 취소.
- Ctrl+Z: 실행 취소. Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행. macOS는 Command 키 사용.
- 🐾: 선택한 카테고리의 동물 소환. 🗂️를 누르거나 동물 버튼을 길게 누르면 카테고리 선택.
- ✋: 동물 잡기 모드. 친구를 누르는 즉시 들어 올리고, 끌다가 손을 놓으면 내려놓기. 작은 친구도 주변을 조금 넉넉하게 눌러 잡을 수 있습니다.
- 👀: 즉시 눈 붙이기 모드. 다시 눌러도 모드 유지. 면이 맞닿은 블록 덩어리를 눌러 살아 있는 친구로 만들기.
- 🍎/🎈/🍮/🌈: 누를 때마다 간식을 순서대로 바꾸고 먹이기 모드로 전환. 동물이나 블록 친구를 누르면 바로 먹이고, 바닥이나 블록 윗면을 누르면 간식 배치.
- 🚂: 기차 놓기 모드. 바닥을 누르면 기차 한 대를 놓고, 기차를 끌어 길을 그리면 그 길을 따라가요.
- 🧹: 동물/블록 친구/먹이/기차 개별 제거 모드. 🧹를 2초간 누르면 친구들과 먹이, 기차 전체 삭제.
- 💣: 카운트다운 후 블록·블록 친구·일반 동물 함께 폭발. ↻: 카운트다운 취소 또는 블록과 블록 친구 복원.
- ×1/×2/×3: 게임 배속.

컴퓨터와 휴대폰 모두 도구 막대의 👀와 간식 버튼으로 바로 놀이를 시작합니다. 블록을 쌓으려면 **✏️**를 누르세요.

## 동물 친구와 특수능력

🗂️에서 **동네 친구·숲과 초원·물가 친구·작은 친구·상상 친구**를 고른 뒤 동물 버튼을 누릅니다. 전체 카테고리는 44종을 모두 포함하며, 말·기린·식스테일·마릴·캥거루도 소환할 수 있습니다. 분류와 이동 능력은 별개라서, 물가 친구 중에도 점프하거나 등반하는 동물이 있습니다.

✏️ 모드에서 친구를 짧게 톡 누르면 특수능력이 나옵니다. 이동시키려면 ✋로 바꿔 잡아주세요.

| 새 친구 | 놀이 |
| --- | --- |
| 수달 | 짧은 물길을 따라 미끄러지고 가까운 친구도 함께 미끄럼을 타요. |
| 판다 | 데굴데굴 굴러 장난감 볼링 핀을 쓰러뜨려요. |
| 문어 | 알록달록 도장을 남기고 가까운 블록에 잠깐 색을 입혀요. |
| 꽃게 | 가까운 간식을 들어 다른 친구에게 배달해요. 간식과 친구를 곁에 놓아주세요. |
| 고슴도치 | 부드러운 꽃이 피고 지나간 자리에 꽃길이 생겨요. |
| 아기 용 | 변신 중이 아닌 친구를 비눗방울에 태워 잠깐 띄워요. 떠 있는 친구를 톡 누르면 뽁 터져요. |

기존 펭귄은 미끄럼, 코끼리·꼬부기는 물뿌리기, 이상해씨는 꽃길, 달팽이는 색깔 흔적을 만듭니다. 양·돼지·곰·잠만보·메타몽·디그다는 말랑하게 찌그러졌다 돌아오고, 거북이는 등딱지 팽이처럼 돌아요. 새 놀이의 장식은 잠시 후 사라지며, 기차에 탄 친구는 대열을 유지합니다. 재주 도중 간식을 먹이면 재주를 마치고 그 간식의 변신으로 바뀝니다.

## 눈을 붙이면 살아나는 블록

✏️로 블록 몇 개를 서로 붙여 쌓은 뒤 **👀**를 누르세요. 직접 만든 블록 덩어리를 누르면 눈이 붙고 움직이기 시작합니다. 👀를 여러 번 눌러도 눈 붙이기 모드가 유지됩니다.

친구의 모양에 따라 능력이 달라집니다.

| 모양 | 능력 |
| --- | --- |
| 키가 큰 친구 | 폴짝 점프하고, 누르면 공중에서 빙글 돌아요. |
| 넓고 납작한 친구 | 낮은 틈으로 기어가고 벽을 타요. 누르면 빠르게 달려요. |
| 그 밖의 덩치 큰 친구 | 블록을 부수고, 누르면 쿵쿵 발을 굴러요. |
| 작고 아담한 친구 | 뒤뚱뒤뚱 움직이고, 누르면 빙글 춤춰요. |

눈 붙이기 모드에서 친구를 다시 눌러 반응과 능력 설명을 보거나, 길게 잡아 다른 곳으로 옮길 수 있습니다. 서로 면이 맞닿은 블록이 한 친구가 되므로, 여러 친구를 만들려면 덩어리 사이를 띄워주세요. 한 친구는 최대 96블록, 가로·세로·높이 각각 12칸까지 만들 수 있습니다.

눈을 붙인 직후 **실행 취소**하면 원래 블록으로 돌아오고, **다시 실행**하면 같은 모양의 친구가 됩니다. 친구가 돌아다닌 경로나 일시적인 간식 변신은 편집 기록에 쌓이지 않습니다.

## 엉뚱한 간식 먹이기

도구 막대의 간식 버튼을 누를 때마다 **🍎 일반 사과 → 🎈 풍선 → 🍮 푸딩 → 🌈 무지개 → 🍎 일반 사과** 순서로 바뀝니다. 버튼에 표시된 간식 하나를 먹일 수 있습니다.

| 간식 | 변신 |
| --- | --- |
| 🍎 일반 사과 | 변신을 풀고 원래 모습으로 돌아와요. |
| 🎈 풍선 | 동글동글 부풀어 둥실 떠올라요. 평소 속도의 40% 이하로 천천히 떠다녀요. |
| 🍮 푸딩 | 말랑해져 바닥과 벽에서 통통 튀어요. |
| 🌈 무지개 | 움직이는 곳마다 무지개 발자국을 남겨요. |

동물이나 살아난 블록 친구를 누르면 선택한 간식을 즉시 먹일 수 있고, 바닥이나 블록 윗면에 놓아 친구가 찾아오게 할 수도 있습니다. 다른 간식을 먹이면 그 간식의 변신으로 바뀝니다.

풍선으로 떠 있는 동안에는 바닥이나 블록 위 먹이를 쫓아가거나 자동으로 먹지 않습니다. 친구를 직접 눌러 간식을 먹이는 것은 가능하며, 일반 사과나 다른 간식을 먹여 풍선을 풀면 다시 먹이를 찾아갑니다.

다른 도구로 바꿔도 간식 순서는 기억합니다. 다시 간식 버튼을 누르면 **다음 간식**으로 바뀌면서 먹이기 모드가 됩니다. 예를 들어 🎈를 쓰다가 👀로 바꾼 뒤 간식 버튼을 누르면 🍮가 됩니다.

변신은 **게임 시간 20초** 뒤 풀립니다. 배속을 높이면 실제 시간으로는 더 빨리 끝납니다. 간식 버튼을 **🍎**가 나올 때까지 눌러 일반 사과를 먹이면 즉시 원래 모습으로 돌아옵니다.

## 친구들과 기차놀이

**🚂**를 누르고 빈 바닥을 톡 누르면 기차가 출발합니다. 가까운 동물부터 한 마리씩 뒤에 합류해 함께 돌아다녀요. 눈을 붙여 만든 블록 친구는 기차에 합류하지 않습니다. 기차놀이 중에는 육식·초식 동물 모두 한 대열로 움직이며 서로를 무서워해 도망가지 않습니다.

풍선으로 떠 있는 동물도 기차에 합류하지 않습니다. 기차를 따라가던 동물에게 풍선 간식을 먹이면 바로 대열에서 빠져나와 둥실 떠다녀요.

기관차와 동물들은 밧줄로 이어져 움직입니다. 달릴 때는 칙칙폭폭 소리가 나고, 가끔 핑핑 소리와 함께 연기를 내뿜어요.

아직 합류하지 않은 친구도 기차가 있는 동안에는 육식동물을 피하지 않아요. 모두 함께 놀 수 있습니다.

움직이는 **기차를 마우스나 손가락으로 끌어 길을 그려보세요.** 그리는 동안 기차가 잠시 멈추고, 손을 떼면 그린 길을 따라갑니다. 반짝이는 길은 잠시 후 사라집니다. ESC, 두 손가락 터치, 다른 도구 선택으로 길 그리기를 취소할 수 있습니다.

길 앞에 블록이 있으면 큰 동물처럼 부수며 지나갑니다. 벽 너머로도 길을 그릴 수 있고, 기차가 실제로 닿을 때 블록이 부서져 뒤따르는 동물들도 통과합니다.

🚂를 다시 눌러도 기차 모드가 유지됩니다. 다른 빈 바닥을 누르면 기차 한 대를 그곳으로 옮깁니다. 🧹로 기차를 지우면 친구들은 다시 자유롭게 돌아다닙니다.

## 폭탄과 복원

💣를 누르면 블록뿐 아니라 살아난 블록 친구와 일반 동물도 함께 날아갑니다. 블록 친구는 **현재 서 있거나 움직이는 자리에서** 블록 조각으로 흩어집니다. 받침 블록이 사라진 먹이는 아래로 떨어집니다.

기차도 폭탄과 함께 정리됩니다. 기차가 필요하면 🚂로 다시 놓으세요.

↻를 누르면 블록과 블록 친구가 복원됩니다. 일반 동물은 **🐾로 다시 소환**하세요. 카운트다운 중에는 ↻로 폭발을 취소할 수 있습니다.
